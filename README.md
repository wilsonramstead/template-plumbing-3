# Plumbing Company Website Template (Design 3)

Plumbing company website template by Wilson Innovations (design 3).

Single-page marketing site for an owner-operated plumbing company. Static `index.html` — inline CSS/JS, no build tools, works from `file://`. Placeholder brand "CopperLine Plumbing" serving the Tampa Bay Area with fictional phone (813) 555-0103; swap in real business name, phone, service area, hours, and reviews before go-live (and remove the `noindex` meta tag then).

## Design
- **Fonts:** Copse (display) + Figtree (body), via Google Fonts.
- **Palette:** Royal blue, sky blue, and warm sand — a clean, dependable water-trade look.
- **Sections:** sticky header with tap-to-call, hero, trust bar, services, "why us," a customer-quote divider, work gallery, testimonials, hours & service area, and a closing call-to-action.
- Fully responsive and accessible: semantic landmarks, alt text, AA-contrast text, visible focus rings, and scroll reveals that respect `prefers-reduced-motion`. Images are lazy-loaded topical stock from Unsplash.

## Deployment
Static single file (`index.html`) — no build step. Hosted on GitHub Pages from the `master` branch, root (`/`).
